# BÀI TẬP 02 - LEARNING APP
## 1. Các công đã sử dụng

- React Native
- JavaScript
- Expo

## 2. Link ứng dụng Expo

https://snack.expo.dev/@ducanh-cdcntt18a/learningapp

## 3. Các component đã xây dựng

Ứng dụng được chia thành 4 component chính:

### Header
- Hiển thị lời chào.
- Hiển thị họ tên sinh viên.
- Hiển thị mã số sinh viên và lớp.

### StatCard
- Hiển thị số lượng khóa học.
- Hiển thị số khóa học đã hoàn thành.
- Hiển thị số khóa học đang học.

### CourseCard
- Hiển thị tên môn học.
- Hiển thị tên giảng viên.
- Hiển thị tiến độ hoàn thành môn học.

### BottomMenu
- Hiển thị thanh menu phía dưới.
- Bao gồm Trang chủ, Khóa học, Lịch học, Cá nhân.
