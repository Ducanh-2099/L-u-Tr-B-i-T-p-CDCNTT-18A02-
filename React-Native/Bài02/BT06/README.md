# Bt06 - ScheduleApp

## 1. Công cụ sử dụng
- React Native
- JavaScript
- useState
- Flat UI Components
- StyleSheet
  
## 2.Chức năng của ứng dụng

- Hiển thị tên ứng dụng và tên sinh viên.
- Hiển thị 7 ngày trong tuần.
- Xem lịch học theo từng ngày.
- Hiển thị tên môn học, phòng học, giờ học và giảng viên.
- Phân biệt môn học bằng màu sắc.
- Thông báo khi ngày được chọn không có lịch học.

## 3. Link ứng dụng Expo

Link ứng dụng Expo: https://snack.expo.dev/@ducanh-cdcntt18a/scheduleapp

## 4. Các component

### Header
Hiển thị tên ứng dụng và tên sinh viên.

### WeekSelector
Hiển thị 7 ngày trong tuần và cho phép người dùng
chọn ngày muốn xem lịch học.

### ScheduleCard
Hiển thị thông tin từng môn học, phòng học,
thời gian và giảng viên.
