
# Bt05 - AnimateApp

## 1. Công cụ sử dụng
- React Native
- JavaScript
- useState
- useEffect
- Animated API

## 2. Link ứng dụng Expo

- Link Expo của ứng dụng: https://snack.expo.dev/@ducanh-cdcntt18a/animateapp

## 3. Các component

### ProgressCard
Hiển thị thông tin mục tiêu và phần trăm tiến độ.

### ActionButton
Tạo nút bắt đầu, hoàn thành và bắt đầu lại mục tiêu.

### AnimatedMessage
Hiển thị thông báo hoàn thành với hiệu ứng phóng to
và mờ dần bằng Animated API.
