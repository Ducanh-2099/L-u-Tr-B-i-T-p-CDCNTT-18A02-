# BÀI TẬP 01 - NODEJS

## 1. Thông tin bài tập

- Môn học: Lập trình Node.js
- Bài thực hành: Bai03 - Bt01
- Tên chương trình: bai01.js

## 2. Yêu cầu bài tập

- Khai báo danh sách gồm 5 sinh viên.
- Mỗi sinh viên gồm: mã, họ tên, tuổi và điểm.
- Sử dụng class và constructor để biểu diễn sinh viên.
- Sử dụng Arrow Function để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng console.log() để hiển thị danh sách sinh viên đạt yêu cầu.

## 3. Các bước thực hiện

### Bước 1: Tạo file bai01.js

Tạo file bai01.js trong thư mục Bt01.

### Bước 2: Viết chương trình

Sử dụng class SinhVien và constructor để khai báo thông tin sinh viên.

Sử dụng phương thức filter() kết hợp Arrow Function để lọc sinh viên có điểm >= 5.

### Bước 3: Chạy chương trình

Mở Terminal tại thư mục Bt01 và thực hiện lệnh:

    node bai01.js

### Bước 4: Kiểm tra kết quả

Chương trình hiển thị danh sách 3 sinh viên đạt yêu cầu trên Terminal.
