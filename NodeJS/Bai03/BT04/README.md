# Bài 4: Thêm và hiển thị dữ liệu MongoDB

## 1.Các bước thực hiện:

### Bước 1: Khởi tạo dự án bằng mã lệnh

npm init -y

### Bước 2: Cài đặt thư viện MongoDB

npm install mongodb

### Bước 3: Kết nối Mongodb
Bằng địa chỉ:

mongodb://127.0.0.1:27017

### Bước 4: Thực hiện chương trình

- Kết nối MongoDB.
- Sử dụng database qlsinhvien.
- Sử dụng collection students.
- Thêm 3 sinh viên bằng insertMany().
- Sử dụng find() để hiển thị danh sách sinh viên.
- Đóng kết nối MongoDB sau khi hoàn thành.
- Dùng deleteMany() để xóa dữ liệu cũ khi chạy lại chương trình.

### Bước 5: Khởi chạy chương trình bằng dòng lệnh

node Bài_04.js
